# Tagent – website

Bron van tagent.nl. `python build.py` bouwt de site naar `dist/`; bij elke push op `main` bouwt en publiceert GitHub Actions de site op GitHub Pages.

Documentatie: `docs/TAGENT_PROJECT_CONTEXT.md` (techniek), `docs/TAGENT_BRAND_GUIDELINES.md` (huisstijl), `docs/VOORTGANG.md` (status), `CHANGELOG.md`.
